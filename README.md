# soda-stereo recorrido virtual
En este proyecto hice una página web sobre la banda argentina Soda Stereo, con un diseño de menú retro de los años 80. En vez de platos de comida, mi menú muestra cuatro álbumes: Soda Stereo (1984), Nada Personal (1985), Signos (1986) y Doble Vida (1988).
Cada álbum tiene su propia página, donde puse una explicación corta y la lista de canciones.


Herramientas usadas

Usé HTML para poner el contenido de la página: títulos, textos, imágenes y enlaces. Usé CSS para el diseño: colores, letras, fondo y animaciones. 


Estructura de archivos

Para organizarme hice seis archivos y una carpeta. El archivo index.html es la página principal con el menú. Después hice una página para cada álbum: soda-stereo.html, nada-personal.html, signos.html y doble-vida.html. El archivo style.css lo hice para guardar los colores, las letras y los efectos. Por último, creé la carpeta imagenes para poner las cuatro portadas.
Como las cinco páginas usan el mismo style.css, todas se ven iguales.


Proceso paso a paso

Primero pensé la idea: un menú retro de Soda Stereo donde cada álbum fuera una opción. Después busqué la información real de cada álbum, como el año, el contexto y las canciones, para no inventar datos. Luego creé los archivos y escribí el HTML de cada página.
Después hice el CSS con el fondo, la tarjeta crema, las letras, los botones y los efectos. Al final probé la página abriendo index.html en el navegador, revisé que los enlaces funcionaran.


Diseño


Me inspiré en un menú de restaurante retro, pero con temática musical. Para el fondo hice un patrón de rombos en rojo rosado, rojo oscuro y blanco usando solo CSS. En el centro puse una tarjeta color crema con un borde oscuro y una sombra roja, para que parezca de papel. Los colores principales son crema, rojo rosado, rojo oscuro, blanco y café oscuro para los textos.
Para las letras usé Bowlby One en los títulos, porque es gruesa y llamativa, y Work Sans en los textos, porque es sencilla y se lee bien. Las dos las traje desde Google Fonts. Las portadas son lo más importante de cada tarjeta, así que las puse grandes dentro de un marco cuadrado.


Contenido de la página


En la página principal puse el título Soda Stereo, el subtítulo Menú de álbumes y la frase Elige un álbum y descubre su historia. Debajo van las cuatro tarjetas, y cada una tiene la portada, el nombre, el año, una descripción corta y el botón Ver álbum.
En la página de cada álbum puse el botón Volver al menú, el nombre y el año, la portada grande, una sección de Concepto y una sección de Canciones. En el Concepto expliqué el contexto, qué representa el álbum, cómo suena, qué buscaba la banda y por qué es importante.


Soda Stereo (1984) es el debut y tiene 11 canciones, con new wave bailable y letras irónicas. Nada Personal (1985) tiene 10 canciones y es el giro hacia el new wave británico. Signos (1986) tiene 8 canciones y un sonido más oscuro y maduro, después de un viaje de la banda por Europa. Doble Vida (1988) tiene 9 canciones y se grabó en Nueva York con Carlos Alomar como productor.


Efectos y animaciones con CSS


Todos los efectos los hice con CSS. Usé hover para que algo cambie cuando paso el mouse por encima, y transition para que ese cambio sea suave. Hice que las portadas crezcan un poquito, que las tarjetas se levanten y se inclinen un poco con una sombra rosada, y que los botones cambien de color. En las canciones hice que se muevan a la derecha y cambien de color.
Las líneas cortadas que separan las canciones son un borde de abajo con estilo dashed. Para que la tarjeta crema aparezca subiendo suavemente cuando carga la página usé keyframes.
